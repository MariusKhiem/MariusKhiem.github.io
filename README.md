# MariusKhiem.github.io

Porteføljen til Marius Nguyen, bygget med React + Vite.

## Kjør lokalt

```bash
npm install
npm run dev
```

## Publisering

Hver push til `main` bygger siden og publiserer den til GitHub Pages
(`.github/workflows/deploy.yml`). I repoet må **Settings → Pages → Source** stå på **GitHub Actions**.
